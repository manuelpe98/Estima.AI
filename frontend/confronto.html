Carica il computo metrico di riferimento e i preventivi ricevuti dalle imprese, ciascuno nel formato in cui te l'hanno mandato: Estima abbina i prezzi alle voci del computo e genera un unico file di confronto, in Excel e PDF, con i totali per ogni impresa affiancati.

1Confronto preventivi imprese

1. Computo metrico di riferimento

Carica il file computo_metrico.xlsx già scaricato da Estima per questo progetto (pulsante "Excel" nel passaggio di revisione del computo, oppure dallo zip completo). È la base su cui verranno confrontati i prezzi delle imprese: viene solo riletta così com'è, nessuna elaborazione AI in questo passaggio.

2. Preventivi delle imprese

Carica insieme i preventivi ricevuti — un file per ogni impresa, tutti in una volta — così com'è ciascuno: PDF, Excel o anche una foto/scansione, nel formato in cui te l'hanno mandato. Per ogni file caricato compare un riquadro con il nome dell'impresa (proposto dal nome del file, modificabile) e il pulsante per interpretarlo: un'AI abbina automaticamente ogni prezzo alla voce di computo corrispondente. Verifica sempre l'abbinamento prima di generare il file finale: dopo l'interpretazione compare una tabella dove puoi correggere a mano qualunque prezzo o nota. Questo passaggio richiede un account connesso e consuma crediti/quota AI (una chiamata per ogni preventivo interpretato) — generare il file di confronto finale, invece, è sempre gratuito, quante volte vuoi.

3. Genera il confronto

Il file segue sempre lo stesso schema: voci raggruppate per categoria con quantità, e per ogni impresa il prezzo unitario e il totale di riga affiancati, con i totali finali in fondo — puoi scaricarlo di nuovo ogni volta che correggi un prezzo, senza costi aggiuntivi.
